# Боты: устройство и настройка

Все боты — это тело GASP (`CBP_SandboxCharacter`) с покрашенным манекеном, AI-контроллер на C++ и Behavior Tree. Тела, деревья и блэкборд создаёт генератор из редакторного модуля `NoFearEditor`, руками их собирать не нужно.

## 0. Сборка

Компилятор MSVC не понимает кириллицу в пути проекта (`C:\Users\долбаеб\...`): UBT пишет пути в response-файлы в UTF-8, а `cl.exe` читает их в cp1251. Поэтому проект открывается и собирается через ссылку с латинским путём:

```
C:\NoFear_Sandbox  →  C:\Users\долбаеб\Desktop\NoFear_Sandbox   (junction)
```

- Открывать редактор только через `C:\NoFear_Sandbox\NoFear_Sandbox_UE_Project\NoFear_Sandbox_UE_Project.uproject` — иначе Live Coding и пересборка из редактора упадут.
- Нужны компоненты Build Tools 2022: MSVC v143 (14.44), Windows 11 SDK 10.0.22621, **.NET Framework 4.8 SDK** (без него не соберётся модуль `NoFearEditor`).
- Ссылку можно удалить командой `rmdir C:\NoFear_Sandbox` — удаляется только ссылка, файлы проекта остаются.

    │   ├── CBP_Bot_Jumper                        │   ├── ANoFearSpitterAIController  плевок, отступление
    │   ├── CBP_Bot_Spitter                       │   └── ANoFearTankAIController     удар с размаху, таран
    │   └── CBP_Bot_Tank                          └── ANoFearShooterAIController      оружие, точность, поводок, BT_NoFear_Soldier

- Команда, цвет, имя и класс контроллера задаются в теле (Class Defaults). Новую разновидность бота проще всего сделать дочерним Blueprint от нужного тела.
- Контроллер сам добавит телу недостающий компонент: монстр — `NoFearMeleeComponent`, стрелок — `NoFearCombatComponent`, напарник — `NoFearRecruitableComponent` (флаги `Add … Component If Missing`).
- Дерево поведения прописано в конструкторе каждого контроллера. Чтобы дать боту другое дерево, сделайте Blueprint от контроллера, поменяйте ему `Behavior Tree` и укажите его в теле как `AI Controller Class`.

## 3. Расстановка на уровне

1. На уровне нужен **Nav Mesh Bounds Volume** на всю проходимую область (клавиша **P** подсвечивает навмеш зелёным). Без навмеша боты стоят на месте. Сейчас он есть только в вашей незакоммиченной версии `DefaultLevel`.
2. Перетащить `CBP_Bot_*` из `Content/Blueprints/Bots` на уровень. Точка, где бот появился, становится его «домом»: туда возвращаются стрелки, вокруг неё бродят монстры.
3. Быстро вызвать ботов во время игры — консоль (**~**):

```
NoFearSpawnBot Monster 3
```

Типы: `Civilian`, `Monster`, `AggroMonster`, `Enemy`, `Ally`, `Companion`. Боты встают в ряд перед камерой лицом к игроку, не больше 20 за раз.

## 4. Генератор ассетов

Код — `Source/NoFearEditor/Private/NoFearBotAssetsLibrary.cpp`. Создаёт:

- `Content/AI/BB_NoFearBot` — блэкборд;
- `Content/AI/BT_NoFear_Soldier`, `BT_NoFear_Monster`, `BT_NoFear_Civilian` — деревья;
- `Content/Blueprints/Bots/CBP_*` — тела из таблицы выше.

Запуск — консоль редактора:

```
NoFear.GenerateBotAssets [trees] [bodies]
```

- Без аргументов создаёт только то, чего нет, и ничего не перезаписывает.
- `trees` пересобирает деревья заново: ручные правки в них пропадут.
- `bodies` заново выставляет готовым телам родителя, команду, цвет, имя, контроллер, оружие, запас здоровья и масштаб (у прыгуна, плевуна и танка); остальные правки тел сохраняются.

Из Python: `unreal.NoFearBotAssetsLibrary.generate_bot_assets(True, False)`.

Отдельная команда `NoFear.GeneratePoseAnimBP` создаёт или чинит пост-процесс AnimBP поз (раздел 7.3).

## 6. Деревья

**BT_NoFear_Soldier** (противник, союзник, напарник):

```
Стрелок (Selector)
├── Перевязка          [HealTarget задан, прерывание Both]: Bandage (к раненому подходит сама)
├── По приказу         [RallyLocation задан, прерывание Both]: Move To RallyLocation (радиус 80) → Wait 0.5
├── Бой                [AttackTarget задан, прерывание Both]
│   ├── Укрытие        [CoverLocation задан]: Move To CoverLocation (радиус 30) → Cover Fight
│   ├── Подавить       [IsSuppressing, прерывание Both]: Shoot (2–3 очереди, вслепую по месту, где видели цель)
│   ├── В открытую     [CanFire, InWeaponRange — прерывание LowerPriority]:
│   │                   Shoot (1–2 очереди) → Find Combat Position → Move To MoveGoal
│   ├── Сменить позицию: Find Combat Position → Move To MoveGoal → Wait 0.3
│   └── Wait 0.5 ± 0.2
├── За лидером         [IsFollowing]: Move To Leader (радиус 250) → Wait 0.4
├── Проверить          [InvestigateLocation задан]: Move To → Wait 3 ± 1 → очистить ключ
└── На точке: Move To HomeLocation → Wait 3 ± 1
```

У «В открытую» прерывание только LowerPriority: `CanFire` мигает на ходу, а с Both начатый шаг вбок обрывался, и бот стоял на месте.

«Перевязка» и «По приказу» стоят выше боя: приказ отряда важнее своей перестрелки. Приказы с укрытием (перебежка, фланг, отход, подкрепление) идут через `CoverLocation` — ветку «Укрытие».

**BT_NoFear_Monster**:

```
Монстр (Selector)
├── Рык                [IsRoaring, прерывание Both]: Wait 1.2
├── Разбежаться        [IsScattering, прерывание Both]: Move To FleeLocation (радиус 150) → Wait 0.5
├── Атака              [AttackTarget задан, прерывание Both]
│   ├── Отступить      [KeepAway, прерывание Both]: Find Retreat Location → Move To MoveGoal (радиус 80)
│   ├── Ударить        [HasAttackToken, прерывание Both]: Melee Attack → Wait 0.2
│   ├── На место       [PackGoal задан, прерывание Both]: Move To PackGoal (радиус 80) → Wait 0.3
│   ├── Кружить: Find Circle Location → Move To MoveGoal (радиус 60) → Wait 0.3 ± 0.2
│   └── Wait 0.3
├── За вожаком         [PackGoal задан, прерывание Both]: Move To PackGoal (радиус 120) → Wait 0.5
├── Проверить          [InvestigateLocation задан]: Move To → Wait 2 ± 1 → очистить ключ
└── Бродить: Find Wander Location (от WanderCenter, 700) → Move To MoveGoal → Wait 3 ± 1.5
```

Куда встать, решает стая (раздел 8.3): дерево только идёт к `PackGoal`. «Кружить» остаётся монстрам без стаи.

**BT_NoFear_Civilian** (решения принимает контроллер, дерево только исполняет):

```
Мирный (Selector)
├── Прячется           [IsCowering, прерывание Both]: Wait 1
├── Паника             [IsPanicking, прерывание Both]
│   ├── Бежать: Move To FleeLocation (радиус 100) → Civilian Shelter
│   └── Civilian Shelter (точки нет или не дойти)
├── Насторожен         [IsWary, прерывание Both]
│   ├── Отойти: Wait 1.5 ± 0.3 → Move To FleeLocation (радиус 80) → Look Around 3 ± 1
│   └── Look Around 2 ± 0.5
└── Бродить: Find Wander Location → Move To MoveGoal → Look Around 4 ± 2
```

Задачи на C++, которые можно использовать в своих деревьях:

| Задача | Что делает |
|---|---|
| **NoFear Shoot** | Стреляет очередями, пока `CanFire`. Очередь 0.35–1 с, пауза 0.3–0.8 с, 2–4 очереди за раз. Одиночное оружие жмёт спуск раз в 0.25–0.5 с |
| **NoFear Cover Fight** | Бой из укрытия: спрятаться (за низким — сидя; перезарядка, если магазин неполон) → выглянуть (встать или шаг вбок) → 1–2 очереди → назад. После 3–5 циклов просит перепроверить укрытие. Свои на линии огня или пустой магазин — сразу назад. Санитар рядом (`IsAwaitingMedic`) — сидит в укрытии и не выглядывает, циклы не считаются |
| **NoFear Bandage** | Перевязка своего (`HealTarget`): подбежать к раненому, присесть рядом, повернуться к нему и 4 с перевязывать (**Bandage Time**). Бег сбили (оглушение, уход от гранаты) — задача идёт снова, а не проваливает ветку, как Move To; не добежала за 15 с (**Approach Time**) — провал. Раненый отошёл дальше 220 см (**Max Patient Distance**) — встать и догнать, время стоит; не догнал за 3 с (**Patient Lost Time**) или раненый погиб — приказ снят (`AbortBandage`), к раненому вернутся через 5 с. Ключ — объект с классом `Actor`, как `HealTarget` (фильтр `Pawn` редактор сбросил бы в None) |
| **NoFear Find Combat Position** | Точка открытого боя в ключ: цель не видна — к месту, где её видели; видна — шаг вбок на дистанции оружия, не загораживая своих |
| **NoFear Melee Attack** | Подходит к цели и начинает подходящую атаку из набора компонента ближнего боя; ждёт её конца |
| **NoFear Find Circle Location** | Точка на кольце вокруг цели (радиус — **Circle Min / Max Radius** контроллера монстра, по умолчанию 400–600 см), на 15–50° дальше по кругу; из 6 вариантов выбирает ту, что дальше от своих у той же цели |
| **NoFear Find Retreat Location** | Точка в 900–1300 см от цели, в пределах ±70° от направления «от цели»; путь не длиннее 1.6 прямой + 200 см, дальше от цели, чем сейчас |
| **NoFear Find Wander Location** | Случайная точка на навмеше в радиусе 800 от `HomeLocation`, не ближе 200 к боту |
| **NoFear Find Chase Location** | Точка на навмеше у последнего известного места цели, не доходя 150 |
| **NoFear Clear Key** | Очищает ключ блэкборда |
| **NoFear Look Around** | Стоит и оглядывается: каждые 1.2 с смотрит в случайную сторону до ±110° от начального направления (Duration 4 ± 1) |
| **NoFear Civilian Shelter** | Мирный добежал: прячется (`NotifyReachedSafety`) |

## 7. Общие настройки контроллера

Class Defaults контроллера → **NoFear | AI**:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Can Attack | да | Выбирать цели. У мирных выключено |
| Update Interval | 0.25 с | Как часто бот пересматривает цели и обновляет блэкборд |
| Max Target Distance | 5000 | Дальше цель не выбирается |
| Target Memory Time | 6 с | Сколько бот помнит цель, которую перестал видеть |
| Attacker Memory Time | 6 с | Сколько помнит того, кто его ранил |
| Target Stickiness | 0.35 | Насколько неохотно меняет цель на другую |
| Investigate Lost Target | да | Идти туда, где потерял цель |
| Investigate Noises | да | Идти на звук выстрелов. У мирных выключено |
| Walk When Calm | да | Без цели ходить шагом, а не бегом |
| Strafe In Combat | да | В бою двигаться боком, лицом к цели. У монстров выключено |
| Leash Radius | 0 | Не уходить от дома дальше этого (0 — без ограничения). У стрелков 1500 |

Восприятие: зрение 3000 см (теряет на 3500), угол 75° в каждую сторону, видит только врагов; слух 4000 см.

Походку (боком, прицел, шагом) контроллер выставляет в структуре `CharacterInputState` тела GASP при каждом обновлении. Имя структуры задаётся в `Input State Property`; если её в теле переименовать, бот перестанет ходить шагом и прицеливаться.

## 7.1. Обнаружение, тревога и поиск

Бот замечает врага не мгновенно: у каждого известного ему актора копится **шкала осведомлённости** 0–1. Состояние тревоги (`ENoFearAlertState`) выбирается по ней:

| Состояние | Когда | Что делает бот |
|---|---|---|
| Calm | Ничего не происходит | Обычное поведение |
| Suspicious | Шкала выше порога «?» (0.25), услышал шаги, увидел труп | Поворачивается к источнику, идёт проверить |
| Combat | Шкала заполнилась, ранили, позвали свои | Тактика своего типа |
| Search | Цель потеряна (прошло `Target Memory Time`) | Обыскивает точки вокруг последнего места цели |

**Скорость обнаружения** зависит от расстояния (ближе 300 см около 0.25 с, на 1000 см около 1.25 с, на 2000 см около 2.25 с), от угла к центру взгляда (боковым зрением втрое медленнее), от стойки (присед вдвое медленнее), от движения (бег вдвое быстрее) и от видимой части тела (голова, корпус, ноги). Выстрел игрока в поле зрения бота выдаёт его сразу, невидимый выстрел даёт осведомлённость 0.6 и направление.

Параметры (Class Defaults контроллера → **NoFear | AI | Detection**):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Detection Speed Multiplier | 1 | Общий множитель скорости. Больше — бот зорче |
| Close / Mid Detect Distance | 300 / 1000 | Опорные расстояния шкалы времени |
| Close / Mid / Far Detect Time | 0.2 / 1.5 / 5 с | Время заполнения шкалы на этих расстояниях |
| Center View Angle | 25° | Внутри этого угла — полная скорость, дальше — боковое зрение |
| Peripheral Detect Factor | 0.33 | Скорость бокового зрения |
| Crouch / Moving Detect Factor | 0.5 / 2 | Присед замедляет, бег ускоряет |
| Suspicious Threshold | 0.25 | Порог «?» |
| Awareness Decay Rate / Delay | 0.2 в с / 1 с | Как быстро шкала спадает, когда врага не видно |
| Suspicious Hold Time | 6 с | Сколько бот остаётся настороженным без новых признаков |
| Footstep Awareness Gain / Cap | 0.3 / 0.9 | Шаги поднимают шкалу, но сами по себе до «!» не доводят (ближе `Close Footstep Distance` = 300 см доводят) |
| Gunshot Hidden Awareness | 0.6 | Что даёт невидимый выстрел |

**Шум.** `ANoFearCharacter` сам шумит при ходьбе: шаг каждые 220 см пути на земле, дальность по скорости. Настройки на персонаже (**NoFear | Noise**):

| Параметр | По умолчанию |
|---|---|
| Make Movement Noise | да |
| Footstep Distance | 220 см |
| Walk / Run / Sprint Footstep Range | 400 / 1200 / 1800 см |
| Crouch Footstep Range | 0 (присед бесшумен) |
| Landing Noise Min Fall Speed / Range | 300 / 1800 |

Скорость до 320 см/с считается шагом, до 620 — бегом, быстрее — спринтом. Стена между источником и слушателем глушит шаги и приземление: слышно только на 60 % дальности (выстрелы стеной не глушатся). Чужой шум в код можно добавить так: `UNoFearBotSubsystem::ReportNoise(...)` для шагов и `UAISense_Hearing::ReportNoiseEvent` с тегом `Gunshot` для выстрелов.

**Общая тревога.** Бот, перешедший в бой, зовёт своих в радиусе **Alert Share Radius** (стрелки 2500 см, монстры 3000, мирные не зовут): они получают цель и её последнее место и сразу переходят в бой. Повторный зов не чаще раза в `Alarm Interval` (3.5 с). Союзники рядом с игроком узнают о врагах, с которыми он дерётся (`UNoFearBotSubsystem::NotifyAttack`).

**Трупы.** Стрелки (кроме напарника, он держится рядом с лидером) замечают тела своих и мирных в поле зрения ближе `Corpse Notice Distance` (1500 см), настораживаются и идут к телу осмотреться. Тело замечается один раз. Тела врагов игнорируются. Мирный от тела паникует (раздел 7.4).

**Поиск.** Потеряв цель, бот идёт в её последнее место, затем проверяет `Search Point Count` (по умолчанию 2) точек в радиусе `Search Radius` (1500 см): по направлению, куда цель уходила, и вне видимости из последней точки. Поиск длится не дольше `Search Duration` (25 с), затем бот ждёт `Search Linger Time` (3 с) и успокаивается. Заметив цель, бот сразу возвращается в бой.

**Отладка.** Консольная переменная `NoFear.AI.Debug 1` подписывает каждого бота (состояние, шкала, число оставшихся точек поиска, цель), рисует линию к цели, жёлтую линию и шар к месту проверки (`InvestigateLocation`) и оранжевые шары в точках поиска. `0` — выключить.

## 7.2. Панель над ботом (HUD)

`ANoFearHUD` рисует над головой бота компактную панель: полоску здоровья (с «хвостом» урона) и знак тревоги в кольце. Реестр ботов ведёт `UNoFearBotSubsystem`. Знак: жёлтый «?» — настороженность, кольцо заполняется вместе со шкалой; красный «!» — бой; оранжевый «?» с полным кольцом — поиск.

Когда показывается панель (режим по умолчанию):

| Кто | Здоровье | Тревога |
|---|---|---|
| Напарник | всегда | если не спокоен |
| Союзник | ближе 3500 см, ранен или под прицелом | если не спокоен |
| Противник | ранен, под прицелом, в бою или ближе 1500 см | если не спокоен |
| Монстр | ранен или под прицелом | если не спокоен |
| Мирный | только раненый | нет |

Панель видна только на экране и при прямой видимости головы от камеры (напарников видно всегда), дальше 5000 см не рисуется, к краю дистанции уменьшается и гаснет. Рисуются не больше 24 ближайших.

Кольца ролей под ногами бойцов отряда и значок роли в панели — раздел 9.2.

Под полоской здоровья — запас гранат «◆ N» (при нуле не рисуется): у напарника и союзников всегда, у врагов — только с `Show Enemy Loadout` в `NoFearHUD` или консольной переменной **`NoFear.HUD.ShowEnemyLoadout 1`**, у монстров и мирных никогда. Над панелью на 1.5 с появляется крик бота («Граната!»).

Над полоской здоровья — полоска страха (раздел 7.5): жёлтая от 30, оранжевая от 60, красная от 85. Видна у людей со страхом от **Fear Bar Min Fear** (30) ближе **Fear Bar Distance** (2500 см), у монстров не рисуется. Выключается **Show Fear Bars** в `NoFearHUD` → **Bots|Fear**.

Консольная переменная **`NoFear.HUD.BotIndicators`**: `0` — выключить, `1` — по правилам (по умолчанию), `2` — показывать у всех без проверки видимости. Остальное — в Class Defaults `NoFearHUD` → **Bots** (дальности показа, цвета, время «недавнего урона»).

## 7.3. Позы и реакции

На каждом `ANoFearCharacter` (игрок и все боты) есть `UNoFearPoseComponent` (`GetPoseComponent()`). Он задаёт повороты костей поверх анимации GASP, а применяет их отдельный пост-процесс AnimBP **`/Game/Blueprints/ABP_NoFearPose`**. Основной `ABP_SandboxCharacter` не тронут.

Как это устроено:

- У меша может быть только один пост-процесс AnimBP, а у манекена он уже есть (`ABP_UEFN_Mannequin_PostProcess`: IK ступней и корректировки). Поэтому `ABP_NoFearPose` — его копия с родителем `UNoFearPoseAnimInstance` и узлом **NoFear Pose** перед выходом. Копия сохраняет все узлы оригинала (IK ступней и остальное), оригинал не изменён и остаётся для других персонажей.
- `ANoFearCharacter` на BeginPlay подставляет `PoseAnimBlueprint` в меш. Подмена идёт только если скелет меша совпадает со скелетом AnimBP (`SK_UEFN_Mannequin`; сейчас так у всех готовых тел). Если у нового тела другой скелет, визуальных поз не будет, а механика реакций (замедление, пошатывание, остановка дерева) работает.
- Если ассет потерян или испорчен: консоль редактора `NoFear.GeneratePoseAnimBP` (или `unreal.NoFearPoseAssetsLibrary.generate_pose_anim_blueprint()`). Команда создаёт копию, если её нет, а если есть — проверяет родителя и узел и чинит.
- Модуль `NoFearEditor` в `.uproject` имеет тип **`UncookedOnly`**, а не `Editor`. Узел AnimGraph живёт в нём, а режим «Играть отдельно» и запуск `UnrealEditor.exe -game` не загружают модули типа `Editor`: без узла AnimBP при загрузке молча пересобирается пустым, и позы не работают. В собранной игре модуль и так не нужен.

| Поза | Когда включается | Что видно |
|---|---|---|
| Flinch (вздрагивание) | Любое попадание. Сила растёт с уроном до **Flinch Full Damage** (25) | Корпус и голова отдёргиваются от стрелявшего, ~0.4 с. Бот ~0.8 с идёт шагом (**Hit Slow Time**) |
| Stagger (пошатывание) | Один удар от 25 % максимального здоровья (**Stagger Damage Fraction**) или попадание в голову. Повторно не раньше чем через 2.5 с после конца | Корпус откидывается от стрелявшего (от удара сзади — вперёд), колени подгибаются. Бот ~0.9 с стоит: дерево на паузе, не стреляет и не бьёт |
| Wounded (раненый) | Здоровье ниже 30 % (выход при 35 %) | Сутулость, голова вниз, хромота: таз качается, колено проседает в такт шагу. Бот ходит только шагом |

Безоружному раненому дополнительно ставится оверлей **Injured** из GASP (у вооружённого поза с оружием остаётся: Injured её сломал бы), он снимается, когда здоровье восстановилось.

У игрока реакции выключены (**React When Player Controlled**), чтобы корпус и прицел не дёргались от попаданий. Включите флаг, если нужны они и у игрока.

Параметры (Class Defaults `PoseComponent` → **Pose | Hit Reaction** и **Pose | Wounded**):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Hit Reactions | да | Реагировать на попадания |
| React When Player Controlled | нет | Реагировать, пока телом управляет игрок |
| Flinch Min Damage / Full Damage | 1 / 25 | Урон ниже минимума — без реакции; при полном — максимальное вздрагивание |
| Flinch Hold Time | 0.1 с | Сколько вздрагивание держится на максимуме |
| Hit Slow Time | 0.8 с | Сколько после попадания бот идёт шагом (0 — без замедления) |
| Stagger Damage Fraction | 0.25 | Доля максимального здоровья за один удар, сбивающая с ног (0 — только выстрел в голову) |
| Stagger On Headshot | да | Попадание в голову шатает всегда |
| Stagger Time / Cooldown | 0.9 / 2.5 с | Длительность и перерыв против «стан-лока» очередью |
| Wounded Stance | да | Включать стойку раненого |
| Wounded Health Fraction / Recover Margin | 0.3 / 0.05 | Порог раненого и гистерезис выхода |
| Limp Pelvis Roll / Knee Bend / Step Rate | 5° / 12° / 1.2 | Размах хромоты |
| Wounded Overlay State | Injured | Оверлей безоружного раненого |

Углы каждой позы — таблица **Poses** на компоненте (кости, углы вперёд/вбок/скрутка, время входа и выхода). Кроме того, у каждой позы есть слот **Replacement Montage**: если в нём монтаж, вместо поворотов костей он проигрывается на основном AnimBP. Так настоящая анимация заменяет процедурную без правки кода.

**Присед.** `ANoFearAIController::SetCrouching(true/false)` вызывает `Crouch()` / `UnCrouch()` персонажа. GASP подхватывает присед сам: капсула 86→60 см, скорость 225 см/с, шаги бесшумны (Crouch Footstep Range 0), обнаружение вдвое медленнее. Сам по себе бот не приседает: вызов из задач дерева или Blueprint (приседание в укрытии — этап 7). `IsCrouching()` возвращает состояние.

**Поднятое оружие в тревоге.** Вооружённый бот в состоянии Suspicious без цели поднимает оружие (поза прицеливания); успокоился — опускает. Параметр контроллера **Raise Weapon When Alert** (да).

**Остановка при пошатывании.** Параметр контроллера **Freeze When Staggered** (да): пока бот пошатнулся, дерево на паузе, движение и огонь остановлены. Выключите, если пошатывание должно быть только визуальным.

**Отладка.** Подпись над ботом (`NoFear.AI.Debug 1`) показывает активные позы, «ранен» и «[crouch]».

## 7.4. Мирные

`ANoFearCivilianAIController` никогда не нападает. Состояние (`GetCivilianState()`, событие **On Civilian State Changed**) решает контроллер по шкале страха (раздел 7.5), дерево только исполняет его через ключи блэкборда.

| Состояние | Когда | Что делает | Тревога (панель) |
|---|---|---|---|
| Calm | Страх ниже 30 | Бродит у дома шагом, останавливается и оглядывается | — |
| Wary | Страх 30–59: дальний выстрел, крик издалека, что-то похожее на монстра краем глаза | Останавливается, **Wary Look Time** (1.5 с) смотрит на звук, отходит шагом на 600–1200 см от него, оглядывается. Не меньше **Wary Duration** (8 с) и пока страх не ниже 30 | «?» |
| Panic | Страх 60 и выше: монстр в поле зрения или напал, драка или выстрел рядом, пуля пролетела близко, ранение, труп, крик соседа, взрыв, граната, паника соседей | Кричит и бежит спринтом к точке бегства, раз в секунду перепроверяет её | «!» |
| Cower | Добежал или бежать некуда | Приседает и закрывает голову руками (поза **CoverHead**) | «!» |

Событие, у которого потолок страха ниже порога паники (дальний выстрел, крик издалека), паники не вызывает, даже если страх уже выше 60.

**Крик.** Паникующий кричит (не чаще раза в **Scream Cooldown**, 4 с): соседи в **Scream Radius** (1500) получают страх крика, но сами уже не кричат, так что крик не идёт цепочкой по всему городу. Монстры слышат крик на **Scream Noise Range** (2500) и идут проверить.

**Успокоение.** Когда страх спал ниже 30, встаёт и идёт шагом (обычно 15–25 с после последней угрозы, рядом со стражем быстрее). С вероятностью **Return Home Chance** (0.5) домой, иначе домом становится место, где успокоился. Спрятавшийся снова вскакивает и бежит, если угроза подошла ближе **Cower Break Distance** (600) и есть куда бежать.

**Ранен.** Ниже 30 % здоровья спринт выключен: паникующий бежит обычным бегом и хромает (поза Wounded из раздела 7.3).

**Точка бегства.** `UNoFearFleeLibrary::FindFleeLocation` (C++ вместо ассета EQS, так проще отлаживать и дешевле):
1. 32 точки по кругу 1500–3000 см (**Flee Min/Max Distance**), спроецированные на навмеш.
2. Отбрасываются точки в сторону любой угрозы.
3. Очки: дальше от ближайшей угрозы, по направлению «от угроз», бонус, если точку не видно ни от одной угрозы.
4. Для 8 лучших синхронно строится путь; отбрасываются недостижимые и пути, проходящие ближе **Safe Path Distance** (500) к угрозе.

Угрозы контроллер помнит **Threat Memory Time** (20 с). Опасности сообщает `UNoFearBotSubsystem::ReportDanger` (тип: Gunshot, NearMiss, Fight, Scream, Explosion, Grenade): оружие зовёт его на каждый выстрел и для каждой пули, ближний бой — на каждый удар. Свои источники (граната, ловушка) — тот же вызов из C++ или Blueprint.

## 7.5. Страх

У каждого персонажа есть `UNoFearFearComponent` со шкалой страха 0–100 (`GetFear`, `GetFearLevel`, событие **On Fear Level Changed**). Пороги: **Anxious** 30, **Panic** 60, **Terror** 85. Считает всё `UNoFearFearSubsystem` раз в **Update Interval** (0.2 с). Числа — Project Settings → **NoFear AI** → **Fear**, на ходу — `GetTuning` / `SetTuning` у подсистемы.

**Кто пугается.** Множитель прироста по команде: мирные 1, враги 0.5, герой 0.6, союзники-стражи 0.35, монстры 0 (не пугаются). У стрелков страх от выстрелов, взрывов и ранений не выше **Combat Fear Cap** (45): к бою они привычны, выше поднимает только монстр.

**Источники** (разовый испуг / потолок):

| Событие | Страх | Потолок |
|---|---|---|
| Выстрел ближе 1500 / дальше | 70 / 35 | 100 / 50 |
| Пуля пролетела рядом | 65 | 90 |
| Драка рядом | 60 | 85 |
| Взрыв / граната | 70 / 65 | 100 / 90 |
| Крик ближе 1000 / до 2500 | 65 / 35 | 75 |
| Труп | 65 | 70 |
| Ранение | 60 | 100 |
| Монстр впервые разглядели: ближе 500 / дальше 3000 | 70 / 35 | 100 / 80 |
| Монстр на виду, в секунду: ближе 500 / дальше 3000 | 40 / 8 | 100 / 80 |
| Что-то похожее на монстра (мирный не разглядел) | 35 | 40 |

Между ближней и дальней дистанцией числа монстра меняются линейно. Потолок значит, что событие не поднимет страх выше этого числа, но и не снизит.

**Спад.** Через **Decay Delay** (6 с) после последнего испуга страх спадает на **Decay Rate** (2.5 в секунду). Рядом живой страж (герой или союзник) в **Guardian Radius** (1200) — спад ×**Guardian Decay Multiplier** (2.5) и начинается вдвое раньше. Каждый спокойный сосед в 800 см добавляет +15 % (не больше +45 %).

**Передача.** Кто сам испугался за последние 5 с и паникует (страх от 60), пугает соседей в **Spread Radius** (800) на **Spread Rate** (6 в секунду за каждого такого соседа, считаются не больше трёх; не выше **Spread Cap** 75). Переданный страх сам дальше не передаётся, поэтому толпа пугается волной, а не вся сразу.

**Стрелки.** Мораль отряда тянется к своей отметке (раздел 9.2), и эта отметка ниже на **Morale Penalty** (0.3) × доля среднего страха бойцов выше 30. Разброс стрелка от страха 60 до 100 растёт линейно до ×**Panic Spread Multiplier** (1.6).

**Успокоение героем.** Подойти к мирному со страхом от 30 ближе 300 см и держать **E** («Успокоить»): герой снимает **Calm Rate** (35 в секунду), пока страх не упадёт ниже **Calm Target Fear** (15), отпустил E или отошёл дальше **Calm Distance** (350) — прерывается. Во время успокоения герой стоит и не стреляет, над мирным кольцо «Успокаиваю». Мирный, у которого страх стал ниже 30, сразу встаёт и идёт шагом, встревоженный — сразу спокоен (`Comfort` у компонента страха; обычный `Soothe` тревогу не сокращает). Компонент `UNoFearCalmComponent` мирный получает при захвате контроллером.

**Отладка.** `NoFear.Fear.Debug 1` — число страха над каждым персонажем. В панели над ботом полоска страха (раздел 7.2).

## 7.6. Страх героя и браслет

Страх героя — та же шкала `UNoFearFearComponent` на его пешке (множитель команды 0.6, потолок от людей 45). Источники, эффекты и способности считает `UNoFearBraceletComponent` на `ANoFearPlayerController` (`GetBracelet`). Числа — Project Settings → **NoFear AI** → **Hero Fear**, на ходу — `GetTuning` / `SetTuning` у браслета. Страх пешки меняется сменой персонажа (**N**): браслет перепривязывается сам.

**Источники героя** (до множителя команды):

| Событие | Страх | Потолок |
|---|---|---|
| Монстр впервые на виду (конус 60°, до 3500, или ближе 500 — чует): ближе 600 / дальше 3000 | 25 / 10 | 100 / 65 |
| Монстр на виду, в секунду: ближе 600 / дальше 3000 | 18 / 3 | 100 / 65 |
| Здоровье ниже 35 %, в секунду | 3…6 (чем меньше здоровья, тем больше) | 45…85 (чем меньше здоровья, тем выше) |
| Урон | 0.5 за единицу, не меньше 4 | 100 (от людей — 45) |
| Напарник упал / пока лежит, в секунду | 20 / 3 | 80 |
| Выстрел врага ближе 2000, пуля рядом, взрыв | 4, 10, 20 | 45 |
| Крик мирного | 4 | 45 |
| Драка монстра рядом | 10 | 75 |
| Труп мирного или союзника на виду (до 2000), один раз на труп | 14 | 60 |

Монстр, которого не видели 12 с, снова пугает разовым испугом. Свои выстрелы и выстрелы союзников героя не пугают. Паника мирных вокруг передаётся герою, как всем (раздел 7.5).

**Облегчение.**
- Спад как у всех. Рядом союзник или напарник — спад быстрее (аура стража).
- Успокоил мирного — минус 8.
- Убил монстра — минус 10.

**Эффекты.**

| Страх | Эффект |
|---|---|
| 30+ | Дрожь прицела (до 0.45°), слышно сердцебиение 70→150 ударов в минуту |
| 60+ | Прицел плывёт (до 1.2°), разброс оружия растёт до ×1.5 к 85, виньетка, хроматическая аберрация, зерно, лёгкий красный оттенок в такт сердцу |
| 85+ | Разброс до ×1.8 к 100, перезарядка медленнее (×0.7), цвета выцветают |

Эффекты идут по сглаженному страху, поэтому не дёргаются. Общую силу экрана задаёт **Screen Effect Scale** (0 — без пост-процесса).

**Ступор.** Страх дошёл до 100 — герой на 1.8 с застывает: не ходит и не стреляет (гранаты тоже), дрожь сильнее, экран почти обесцвечен. После ступора страх 80, следующий ступор не раньше чем через 20 с.

**Стабилизация — Q** (геймпад: крестовина вниз). Браслет за 1.5 с снимает 40 страха. Перезарядка 45 с.

**Задержка дыхания — Alt** (геймпад: нажатие левого стика), только пока герой целится. Пока держит: дрожь и увод прицела гаснут, половина прибавки разброса от страха снимается. Но страх растёт в 1.5 раза быстрее и не спадает. Запаса хватает на 4 с, восстановление 6 с. Выдохнул до дна — снова задержать можно через 3 с.

**Браслет в HUD** — слева внизу над здоровьем:
- полукруглая шкала с рисками порогов, цвет по уровню;
- число страха пульсирует в такт сердцу;
- справа кольцо **Q** (готовность стабилизации, секунды до неё) и полоска **Alt** (запас дыхания);
- в ступоре над шкалой мигает «СТУПОР».

Отключается флагом **Show Bracelet** у HUD.

**Разлом.** `ReportRift(Location)` у браслета: три коротких сигнала и стрелка «РАЗЛОМ N м» вверху экрана на 3 с. Подсистема порталов зовёт его сама, когда портал открывается или дорастает до новой ступени ближе 60 м от героя (раздел 7.7).

**Консоль.**
- `NoFearHeroFear [число]` — поставить страх героя (по умолчанию 100 — ступор).
- `NoFearRift [расстояние]` — проверить предупреждение о разломе впереди.
- `NoFear.Hero.Debug 1` — строка состояния браслета: страх, монстры на виду, разброс, пульс, ступор, перезарядки, источники.

## 7.7. Порталы страха

Слом людей, порталы и освобождение считает `UNoFearPortalSubsystem` (мировая подсистема) раз в **Update Interval** (0.1 с). Числа — Project Settings → **NoFear AI** → **Portal**, на ходу — `GetTuning` / `SetTuning` у подсистемы. Портал — актор `ANoFearPortal`: провал-сфера, светящийся диск на земле, свет и лучи к проводникам. Он пульсирует чаще с каждым проводником, а затягиваясь, дрожит и схлопывается.

**Слом.** Ломаются боты-люди: мирные, союзники, враги. Герой, монстры и раненые не ломаются. Слом копится, пока страх не ниже **Break Fear** (99.5) и прямой испуг был не раньше **Break Fresh Time** (1.5 с) назад. Переданный страх (паника соседа, край ауры) прямым не считается. Мирный ломается за **Break Time** (3 с), стрелки — за **Shooter Break Time** (6 с). Не в ужасе — слом стекает с той же скоростью (**Break Drain Scale** 1). Сломавшийся кричит (испуг «Крик» в 1500 см).

**Куда идёт сломавшийся.** Есть открытый портал ближе **Join Radius** (1800) — питает его. Затягивающийся портал рядом открывается снова. Порталов уже **Max Portals** (3) или с прошлого открытия прошло меньше **Open Cooldown** (8 с) — питает ближайший, где бы тот ни был. Иначе открывает разлом размером **Start Size** (5) в **Open Distance Min–Max** (350–600 см) от себя: в сторону источника страха, на навмеше, лучше на виду.

**Проводник.** `SetPortalTrance` у контроллера: дерево на паузе, поза `Trance` (тянется к порталу), фокус на портал, скорость 0. Страх держится на 100. Успокоить нельзя: `UNoFearCalmComponent` не предлагает «Успокоить», вместо него на проводнике появляется `UNoFearFreeComponent` — «Освободить (держать E)». Раз в 7 с проводник шепчет. Соседей в **Feeder Fear Radius** (900) он пугает на **Feeder Fear Rate** (5 в секунду, не выше **Feeder Fear Cap** 80) — не прямой испуг, сам по себе не ломает. Монстры проводников не выбирают целью. Проводника убили — он больше не питает. Ранен — снят с портала, а поднятый **Break Immunity Time** (20 с) не ломается.

**Рост.** Рост в секунду = **Feed Rate** (1) × N^**Feed Exponent** (0.8), где N — число проводников: один — 1, двое — 1.74, четверо — 3.03. Без проводников портал сжимается на **Starve Rate** (3 в секунду) и в 0 затягивается.

| Ступень | Размер | Монстры | Интервал | Живых не больше |
|---|---|---|---|---|
| Трещина | 0–20 | нет | — | — |
| Малый | **Small Size** 20 | одиночный монстр | 18 с | 2 |
| Средний | **Medium Size** 45 | 2 за раз: монстр, прыгун, плевун | 20 с | 5 |
| Большой | **Large Size** 75 | 3 за раз, в волне танк | 15 с | 8, танков 1 |

Первый монстр выходит через **First Spawn Delay** (4 с) после перехода на малый. Новая ступень сокращает ожидание следующей волны до того же времени. Всех монстров порталов не больше **Max Monsters** (16). Монстр выходит у края провала с командой `Monster` и бродит на поводке **Monster Leash Radius** + **Monster Leash Per Size** × размер (1200 + 10 × размер). Виды — **Monster/Jumper/Spitter/Tank Class**.

**Аура.** Радиус **Aura Radius** + **Aura Radius Per Size** × размер (800 + 12 × размер). Внутри доли **Aura Core Fraction** (0.35) — сердце: прямой испуг **Aura Fear Rate** (10 в секунду) до **Aura Core Cap** (100), стоящего там ломает. До края — вдвое слабее, переданный, до **Aura Edge Cap** (80). Множитель команды действует, героя аура тоже пугает.

**Освобождение героем.** У проводника ближе **Hero Free Distance** (260) держать **E**: за **Hero Free Time** (3.5 с) он очнётся. Пока держит, герой стоит и не стреляет, успокоение и подъём раненого прерываются. Отпустил E или отошёл (с запасом 60 см) — освобождение после 0.35 с без рук спадает на **Free Progress Decay** (0.2 в секунду). Из Blueprint: `StartHeroFreeing(PC, Feeder, bHeldByInput=false)` идёт до `StopHeroFreeing`.

**Стражи.** Свободный союзник не в бою (цели ближе **Guardian Combat Distance** 2000 нет) берёт ближайшего проводника до **Guardian Search Radius** (2500). Одного проводника выводит один страж. Он кричит, идёт к проводнику и, подойдя на **Guardian Reach** (160), выводит его из транса за **Guardian Free Time** (8 с). Появился враг или страж не дошёл за **Guardian Approach Time** (15 с) — бросает и не берётся снова **Guardian Retry Time** (5 с). Освобождение героя и стража складывается.

**Очнулся.** Страх **Freed Fear Min–Max** (60–66), транс снят, мирный бежит прочь от портала, слом **Break Immunity Time** (20 с) не копится. Браслет засчитывает героя, как за успокоение.

**Затягивание.** Начинается, когда размер дошёл до 0, или по `ClosePortal`. Проводники очнутся, монстры портала под управлением подсистемы бегут к нему (`SetPortalControl`) и уходят в него ближе **Recall Reach** (220). Кто не успел за **Recall Time** (6 с), растворяется. После этого портал исчезает, страх людей в его ауре падает на **Close Relief** (30).

**HUD** (`ANoFearHUD`, категория **Portals**):
- аура пунктиром и сердце сплошным кольцом на земле;
- над провалом «ПОРТАЛ · ступень», полоска размера с рисками ступеней, «проводники N · монстры N»;
- у ног проводника пульсирующее кольцо и дуга освобождения;
- у того, кто вот-вот сломается, мигающая дуга слома;
- у прицела кольцо «Освобождаю».

Настройки: **Show Portals**, **Portal Color**, **Portal Mark Distance** (6000 — дальше подпись портала гаснет), **Portal People Distance** (3000 — то же для колец у людей).

**Консоль.**
- `NoFear.Portal.Break [радиус]` — сломать ближайшего к игроку человека (с числом — всех в радиусе).
- `NoFear.Portal.Open [расстояние=600] [размер]` — открыть портал перед игроком.
- `NoFear.Portal.SetSize N` — размер ближайшего портала.
- `NoFear.Portal.CloseAll` — затянуть все порталы.
- `NoFear.Portal.FreeAll` — вывести из транса всех проводников.
- `NoFear.Portal.Debug 1` — аура и сердце кругами, над порталом размер, ступень, проводники и монстры. Над людьми слом и освобождение, от стража к проводнику — зелёная линия.

## 8. Монстры

### 8.1. Набор атак

Задача **Melee Attack** выбирает из атак, доступных по дистанции и перезарядке, случайную с учётом веса. Новая атака — наследник `UNoFearMonsterAttack` в C++ или Blueprint (виртуальные `CanUse`, `BeginWindup`, `BeginStrike`, `TickStrike`, `ApplyHit`).

| Параметр атаки | Swing | Lunge | Смысл |
|---|---|---|---|
| Min / Max Range | 0 / 260 | 200 / 480 | С какого расстояния начинает |
| Cooldown | 1.2 | 3.5 | Перезарядка этой атаки, с |
| Weight | 1 | 1.5 | Вес при случайном выборе |
| Damage | 20 | 30 | Урон |
| Hit Reach / Hit Radius | 100 / 90 | 90 / 80 | Куда и какой сферой бьёт перед собой |
| Knockback Speed / Up Speed | 0 / 0 | 0 / 0 | Отбрасывание задетого |
| Windup / Hit Window / Recovery | 0.35 / 0.25 / 0.35 | 0.45 / 0.45 / 0.5 | Замах (доворачивается к цели), окно удара, восстановление |

### 8.2. Окружение и жетоны

Так бьют монстры без стаи (в стае очередь задают волны, раздел 8.3). Бить одну цель одновременно могут не больше **Max Attackers Per Target** (2, `UNoFearBotSubsystem`) монстров. Остальные кружат вокруг на 400–600 см, обходя цель с разных сторон, и ждут. Ударивший отдаёт жетон ожидающему и сам сможет взять его снова не раньше чем через **Token Pass Delay** (2 с). Держатель, который не ударил за **Token Hold Timeout** (8 с), теряет жетон, если его ждут другие: застрявший или не достающий до цели монстр не запирает остальных кружить вокруг. Выключить очередь для монстра — **Use Attack Tokens** у контроллера.

### 8.3. Стая

Стаи ведёт `UNoFearPackSubsystem` (подсистема мира). Дома и территории у монстров нет.

- **Кто в стае.** Монстры одной команды с одинаковым **Pack Name** на теле (`ANoFearCharacter`) — одна стая, где бы ни стояли. Без имени стая собирается из стоящих ближе **Pack Form Radius** друг к другу (по цепочке); спокойные стаи без имени при встрече сливаются. Монстр без имени, отставший от спокойного вожака дальше **Leave Distance**, уходит из стаи. Агрессивные монстры в стаи не входят.
- **Вожак** — старейший монстр стаи (появился раньше всех).

| Состояние | Когда | Что делает |
|---|---|---|
| Roam | Цели нет | Вожак шагом бродит по карте шагами по **Roam Stride** (1200) вперёд, курс понемногу гуляет. Остальные идут клином за ним |
| Gather | У стаи есть цель, она далеко | Вожак бегом ведёт стаю к цели, остальные бегут цепью по бокам. Отставший дальше **Straggler Distance** — вожак ждёт его, но не дольше **Max Hold Time** |
| Encircle | Вожак подвёл стаю к видимой цели ближе **Engage Distance** или кто-то уже ближе **Contact Distance** | Стая расходится по местам кольца вокруг цели (радиус — середина **Circle Min / Max Radius** монстра, 500 см). На дальние места идёт в обход, а не сквозь цель |
| Attack | На местах **Encircle Ready Fraction** кольца или прошло **Encircle Max Time** | Бьют волнами с разных сторон: в стае из 5 и больше — по 3, иначе по 2. Волна, которая ударила или не успела за **Wave Max Time**, уступает следующей. Остальные стоят в кольце и отрезают отход |
| Scatter | Погиб вожак | Стая **Scatter Time** разбегается от угрозы на **Scatter Min..Max Distance**, потом новый вожак рычит и собирает её снова |

Цель ушла от всех дальше **Disengage Distance** — стая снова собирается и догоняет.

- **Цель стаи** — цель вожака, иначе самая частая у остальных. Кто цель видит или в кого она только что попала (за **Pack Intel Time**), сообщает остальным, где она. Поэтому выстрел издалека в любого монстра поднимает всю стаю, и она бежит к стрелку.
- **Самооборона.** Цель, которая сама била монстра за последние **Self Defense Time** (2 с) и стоит ближе **Self Defense Distance** (700), он бьёт без очереди.
- **Рык.** Первый, кто заметил цель, рычит (поза Roar, шум): стая получает цель и бежит, но сама не рычит.
- **Слух.** Зрение хуже, чем у людей (1800 см, ±70°), слух дальше: **Hearing Range Scale** 1.75 к дальности любого шума, шаги слышны громче. На шум монстр бежит, а не идёт. Цель выбирает до 8000 см, помнит 15 с.

### 9.1. Укрытия и бой

**Поиск укрытия** (`UNoFearCoverLibrary::FindCover`, C++ без EQS). Каждые 0.8–1.4 с контроллер перебирает точки навмеша на кольцах вокруг себя в радиусе **Cover Search Radius**. Для каждой точки идут лучи к угрозе на высоте присевшего и стоящего:
- закрыты оба — высокое укрытие, закрыт только нижний — низкое;
- препятствие дальше **Cover Max Obstacle Distance** — точка сдвигается к нему и проверяется ещё раз;
- точка ближе **Min Cover Threat Distance** (500) к угрозе отбрасывается, путь к ней должен быть полным;
- у высокого укрытия ищется точка выглядывания сбоку (шаг 60–180 см), откуда цель видна; у низкого стреляют стоя с той же точки.

Лучшее по очкам: можно выглянуть (высокое чуть лучше низкого), в дистанции оружия, ближе к себе. При отходе важнее, насколько дальше от угрозы. Укрытие бронируется в `UNoFearBotSubsystem`: чужая бронь или другой бот ближе **Cover Reserve Radius** — занято, поэтому двое не встают в одно место. Угроза подошла ближе 0.8 от минимума или укрытие перестало закрывать — ищется новое.

**Бой из укрытия** — задача **Cover Fight** (см. раздел 6). За низким бот сидит и встаёт стрелять, из-за высокого выходит на точку выглядывания. Перезарядка в укрытии, если в магазине меньше **Cover Reload Fraction**; без цели — меньше **Idle Reload Fraction** (1/3). Цель не видна дольше **Advance After Unseen Time** — бот бросает укрытие и подходит.

**Линия огня.** Свой на линии к цели снимает `CanFire`: из укрытия бот прячется, в открытую — шагает вбок (Find Combat Position выбирает точку, с которой линия чистая).

**Дистанция по оружию.** `BotPreferredRange` в ассете оружия; 0 / 0 — по типу: дробовик 0–700 (сближается), пистолет 400–1200, винтовка 800–2000. `InWeaponRange` — цель в этом коридоре; укрытия и точки боя выбираются в нём.

**Без укрытия** бот не стоит на месте: 1–2 очереди и шаг на новую точку.

**Отход раненого.** Здоровье ниже **Retreat Health Fraction** (30 %) — бот ищет укрытие в радиусе **Retreat Search Radius**, дальше от угрозы минимум на **Retreat Gain**, кричит «Прикройте!» и отходит (`IsRetreating`). Боец отряда просит свой отряд: прикрывают двое ближайших (раздел 9.2, приказ CoveringFire). Без отряда — свои стрелки в **Cover Fire Request Radius**. Прикрывающие кричат «Прикрываю!» и **Covering Fire Time** секунд прячутся меньше и стреляют дольше.

**Поиск для отряда.** Тот же `FindCover` ищет укрытия и по приказам (раздел 9.2): **на фланге** — под углом не меньше Min Flank Angle у врага между отрядом и точкой, только с точкой выглядывания и со скрытым путём (с пути врага не видно; путь не длиннее прямого в 2.2 раза), радиус 2500; **при отходе** — дальше от врага и ближе к рубежу (`GoalLocation`); **для подмоги** — вокруг прижатого своего. Боец в отряде держится поводка отряда: вокруг постов отряда (**Squad Leash Radius**, 2500), после отхода — вокруг рубежа.

Настройки — `NoFearShooterAIController`, раздел **NoFear | AI | Cover**:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Use Cover | вкл. | Выключено — только открытый бой со сменой позиций |
| Cover Search Radius | 1500 | Где искать укрытие |
| Min Cover Threat Distance | 500 | Укрытие не ближе к угрозе |
| Cover Search Interval | 0.8–1.4 с | Как часто перепроверять |
| Cover Reserve Radius | 150 | Радиус брони |

| Cover Reload Fraction | 0.6 | Перезарядка в укрытии |
| Idle Reload Fraction | 0.33 | Перезарядка без цели |
| Advance After Unseen Time | 6 с | Цель не видна — подойти |
| Retreat Health Fraction | 0.3 | Порог отхода, 0 — не отходить |
| Retreat Search Radius | 2500 | Где искать укрытие для отхода |

### 9.2. Отряды

**Отряд** — стрелки одной команды с одинаковым полем **Squad** на теле (`ANoFearCharacter`, раздел **NoFear | Squad**). Пустое поле — боец сам по себе. Напарник в отряды не входит, монстры — тоже (у них стаи, раздел 8.3). В отряде не больше 6 бойцов; лишние воюют в одиночку. Регистрировать отряд не надо: `UNoFearSquadSubsystem` каждые 0.2 с пересобирает состав из живых стрелков, погибший выбывает сам.

**Роль** — поле **Squad Role** там же:

| Роль | Оружие | Кольцо под ногами | Значок в панели |
|---|---|---|---|
| Командир | Винтовка | Золотое двойное | Корона |
| Штурмовик | Дробовик | Оранжевое сплошное | Шеврон вверх |
| Поддержка | Винтовка | Голубое пунктирное | Две черты |
| Стрелок | Винтовка | Белое тонкое | Точка |

Пустая роль (`None`) — стрелок. Командира можно задать на теле; если его нет, командиром становится первый стрелок, за ним — поддержка, потом штурмовик. Погиб командир — роль переходит к следующему по тому же правилу. Два командира на телах — второй становится стрелком.

**Оружие роли** — карта **Role Weapons** в `NoFearShooterAIController` (раздел **NoFear | AI | Squad**): по умолчанию штурмовику — `DA_Shotgun`. Бот берёт это оружие (если его нет — добавляет) и с ним идёт по дистанциям из раздела 9.1: дробовик сближается. Сменили роль на ходу — бот возвращается к первому оружию.

**Как поставить отряд вручную:**
1. Перетащить на уровень 2–6 ботов `CBP_Bot_Enemy` (или `CBP_Bot_Ally`).
2. У каждого в **Details → NoFear | Squad** вписать одно имя в **Squad**, например `Alpha`. Имя важно только внутри команды: `Alpha` у врагов и `Alpha` у союзников — разные отряды.
3. Раздать **Squad Role**: одному — `Commander`, одному-двум — `Assault`, одному — `Support`; остальным можно оставить `None`.
4. Запустить игру — над отрядом на 1.5 с появятся линии к командиру.

Для бота, созданного из Blueprint, `Squad` и `Squad Role` открыты при спавне (Expose on Spawn).

**Общее знание о врагах.** Враг, которого кто-то из бойцов видел не дольше **Squad Intel Time** (1 с) назад, сообщается остальным — где бы они ни стояли, хоть спиной к бою. Через **Enemy Memory Time** (30 с) без взгляда отряд его забывает.

**Распределение целей.** Оценка цели (`ScoreTarget`) делится на `1 + Squad Target Share Penalty × N`, где N — сколько бойцов отряда уже бьют эту цель (Penalty 0.5). При нескольких врагах отряд расходится по ним; единственную цель бьют все.

**Бой и главная угроза.** Отряд в бою, если у кого-то из бойцов есть цель или кого-то из врагов видели не дольше **Combat Memory Time** (8 с) назад. Главная угроза — враг, в которого целится больше бойцов (поровну — которого видели последним). Если она не отходит дальше 300 см, отряд считает, что враг **засел**: от этого зависят фланг и граната.

#### Мораль

У отряда шкала морали от 0 до 1, на старте **Start Morale** (0.7).

| Событие | Изменение |
|---|---|
| Погиб боец / погиб командир | −0.2 / ещё −0.25 |
| Ранения | −0.2 за полное здоровье бойца |
| Боец под подавлением | −0.03 в секунду |
| Граната рядом (боец убегает) | −0.08 |
| Убили врага | +0.15 |
| Пришёл соседний отряд / дошла подмога / перевязка | +0.15 / +0.05 / +0.05 |

Сама по себе мораль тянется к «спокойной» отметке `0.7 + 0.08 × (своих − врагов) − 0.25 × доля потерь` (в пределах 0.3–0.9): в бою на 0.01 в секунду, вне боя на 0.05. Средний страх бойцов выше 30 опускает эту отметку (до −0.3 при страхе 100, раздел 7.5). Бойцы, ушедшие помогать соседям, на мораль своего отряда не влияют.

| Порог | По умолчанию | Что разрешает |
|---|---|---|
| Rush Morale | 0.65 | Не ниже — натиск |
| — | 0.5 | Не ниже — фланг |
| Assist Morale | 0.45 | Ниже — звать соседний отряд |
| Defend Morale / Defend Exit Morale | 0.4 / 0.5 | Ниже первого — оборона; выход из неё — выше второго |
| Fallback Morale | 0.2 | Ниже — отход перекатами |

#### Тактики

Командует подсистема (`UNoFearSquadSubsystem`), игрок отрядам не приказывает. Тактика пересматривается раз в **Tactic Think Interval** (1 с). Новая держится не меньше **Min Tactic Time** (3 с), а начатый манёвр (перебежки, фланг, натиск, отход) доводится до конца. Проверки идут по порядку, первая сработавшая выбирает тактику:

| Тактика | Когда | Что делают бойцы | Крик |
|---|---|---|---|
| — (нет) | Боя нет; или кто-то обыскивает | Каждый на своём посту / ищет сам | — |
| **Сбор** | Бой был и закончился | Все к командиру (после отхода — на рубеж), кольцом в 200 см; раненых перевязывают. Конец — все на местах и перевязаны или 30 с | «Все ко мне!», в конце «По местам!» |
| **Контакт** | Бой начался после 10 с затишья | **Contact Duration** (2.5 с) все ищут укрытие лицом к угрозе. Враг дальше, чем бьёт оружие, — укрытие рядом: не дальше от врага и не больше чем на **Contact Cover Advance** (600, у контроллера) ближе; нет такого — стоять на месте. Сближаться — дело перебежек, а не одиночек | Заметивший — «Контакт!», командир — «К бою!» |
| **Отход** | Убит командир (в течение 15 с); ранены все (здоровье ниже **Wounded Fraction**, 50 %); мораль ниже 0.2 | Перекатами к рубежу, см. ниже | «Командир убит! Отходим!» / «Все ранены! Отходим!» / «Отходим! Перекатами!» |
| **Оборона** | После отхода — на рубеже до конца боя; или мораль ниже 0.4 | Все держат позиции, никто не уходит вперёд | «Держим позиции!» / «Держим рубеж!» |
| **Натиск** | Мораль ≥ 0.65, живых ≥ 2, главная угроза ближе **Rush Max Distance** (2500) и видна последние 3 с, и она перезаряжается, ранена (< 40 %) или прижата (подавлена, или по ней бьёт большинство, а по отряду 2 с не попадали) | Поддержка (нет её — командир, если живых ≥ 3) и раненые подавляют, остальные бегут к укрытию на **Rush Gain** (500) ближе к врагу, нет укрытия — сближаются в открытую. До **Rush Max Time** (6 с), потом **Rush Cooldown** (10 с) | «Перезаряжается! Дави!» и т. п. |
| **Фланг** | Живых ≥ 3, мораль ≥ 0.5, враг засел **Flank Dug In Time** (5 с) и виден последние 8 с, кулдаун **Flank Cooldown** (8 с) прошёл | Штурмовик (нет его — стрелок) идёт скрытым путём к укрытию под углом ≥ **Flank Min Angle** (60°) от линии отряда; остальные подавляют. Укрытие для фланга ищется шире обычного: точки на кольцах гуще (до 90 на кольцо), до врага до **Flank Max Threat Distance** (2500, у контроллера), поводок ×1.5. Флангер уже стоит под таким углом — сразу перекрёстный огонь. Дойдя, **Flank Fire Time** (6 с) бьёт из укрытия, пока отряд прижимает. Конец — дошёл и отстрелял, застрял, ранен или **Flank Max Time** (20 с) | Командир — «Обходи справа/слева!», флангер — «Обхожу!», дойдя — «На позиции!» |
| **Перебежки** | Живых ≥ 2 и врага не достать: не виден **Bound Hidden Time** (3 с) или большинство бьющих вне дистанции своего оружия | Две группы через одного (командир — в группе A). Идущая берёт укрытие на **Bound Gain** (300) ближе к врагу, стоящая подавляет; раненые не бегают. Смена групп — когда все дошли или **Bound Phase Max Time** (8 с). Конец — **Max Bound Swaps** (6) смен, две фазы подряд никто не смог пойти, или врага уже достают: вне дистанции меньше половины бьющих. Начинаются перебежки, когда вне дистанции больше половины, а идут, пока не меньше половины, — так вторая группа тоже успевает подтянуться | «Перебежками, вперёд!», идущие — «Двигаюсь!» |
| **Бой** | Всё остальное | Каждый воюет сам: укрытие, огонь, смена позиций | — |

**Отход перекатами.** Рубеж — посты отряда, если они заметно (на 500 см) дальше от врага, чем отряд сейчас. Иначе — точка на навмеше на **Fallback Distance** (1500, потом 2/3 и 1/3 от неё) прочь от врага, до которой есть путь. Бойцы делятся на две группы через одного по удалённости от врага; первой отходит группа ближнего к врагу. Отходящие ищут укрытие дальше от врага и ближе к рубежу (нет укрытия — идут к рубежу в открытую), вторая группа прикрывает огнём. Группы меняются так же, как в перебежках. Все в **Fallback Arrive Radius** (700) от рубежа, **Max Fallback Swaps** (4) смен или 30 с — отряд держит рубеж (оборона с поводком **Fallback Leash Radius**, 900) до конца боя. Новый отход — не раньше **Fallback Cooldown** (20 с). Кто на рубеже оказался дальше поводка (отстал), получает приказ «отходит» и подтягивается к рубежу перекатами: дошёл до укрытия по пути, постоял 3 с — следующий перекат. Раненый, который уже отходит сам (раздел 9.1), отход отряда не ломает.

#### Приказы

Каждые 0.2 с подсистема раздаёт бойцам приказы по тактике; контроллер читает свой приказ (`GetSquadOrderInfo`) и выполняет его через укрытие и блэкборд. Приказ с новым номером — только когда он правда другой (иначе боец искал бы укрытие заново каждые 0.2 с).

| Приказ | Слово в панели | Как выполняется |
|---|---|---|
| TakeCover | в укрытие | Найти укрытие, если его нет |
| Suppress | подавляет | `IsSuppressing`: ветка **Подавить** — стрелять туда, где цель видели свои, даже если её не видно. Вперёд не идёт: враг вне дистанции — только укрытие рядом (как в контакте), открытая позиция — без шага к врагу |
| Bound | перебегает | Укрытие на Bound Gain ближе к врагу |
| Flank | обходит | Укрытие на фланге, найденное командиром (`SearchFlankCover`) |
| Rush | натиск | Укрытие на Rush Gain ближе, иначе сближение в открытую |
| Hold | держит | Не уходить вперёд из укрытия; без укрытия — смена позиции без шага к врагу |
| FallBack | отходит | Укрытие дальше от врага и каждый раз ближе к рубежу, иначе к рубежу (`RallyLocation`) |
| CoverFallback | прикрывает | Подавлять, пока отходит другая группа; вперёд не идёт, как Suppress |
| CoveringFire | прикрывает | Прикрытие своего, который отходит раненым; вперёд не идёт, как Suppress |
| Reinforce | на помощь | Укрытие в **Reinforce Search Radius** (700) от прижатого своего, иначе встать в 350 см от него |
| Heal | перевязка | `HealTarget`: ветка **Перевязка** |
| Regroup | сбор | `RallyLocation`: ветка **По приказу** |
| Assist | к соседям | `RallyLocation` — к соседнему отряду (см. «Соседний отряд» ниже), пока свой враг не попался на глаза |

Помощь соседям стоит выше помощи своим, а помощь своим — выше приказа по тактике. Того, кого сейчас перевязывают, тактика не двигает (кроме отхода).

#### Помощь

- **Прикрытие.** Раненый, который отходит, кричит «Прикройте!» и просит отряд (`RequestCoveringFire`): **Covering Fire Helpers** (2) ближайших свободных в 3000 см, поддержка — первой, **Covering Fire Time** (8 с) прикрывают огнём («Прикрываю!»). Бойцы без отряда прикрывают по-старому (раздел 9.1).
- **Подмога.** Боец под подавлением дольше **Reinforce Pinned Time** (2 с) или только что раненый ниже **Reinforce Health Fraction** (60 %) кричит «Прижали!» / «Ранен!». К нему идут 1–2 ближайших свободных в **Reinforce Radius** (2000) — «Держись, иду!». Дошли до **Reinforce Arrive Radius** (700) или прошло **Reinforce Max Time** (12 с) — помощь снята. Не чаще раза в **Reinforce Cooldown** (15 с) на бойца; не во время контакта и отхода. Командир идёт, только если в отряде двое.
- **Перевязка.** Один санитар за раз. В бою перевязывают тех, у кого меньше **Heal Combat Fraction** (50 %), до **Heal Combat Target** (70 %); после боя — всех ниже **Heal Rest Fraction** (95 %) до полного. Раненый не должен получать урон **Heal Safe Time** (3 с) и не должен быть в пути по приказу. Санитар — поддержка, нет её — ближайший здоровый не дальше **Heal Max Distance** (2000) («Перевяжу, держись!»). Санитар бежит к раненому и 4 с перевязывает присев (задача **NoFear Bandage**, «Готово!»). Раненый, к которому санитар ближе **Medic Wait Radius** (600), сидит в укрытии; без укрытия — стоит на месте (`IsAwaitingMedic`). Не добежал за **Heal Order Timeout** (25 с) или потерял раненого — повтор через 5 с. Одного бойца перевязывают не чаще раза в **Heal Cooldown** (20 с).
- **Соседний отряд.** Отряд в обороне, в отходе или с моралью ниже 0.45 зовёт ближайший свободный отряд своей команды в **Assist Radius** (5000) — «Нужна помощь!». Свободный — не в бою, не на тревоге, сам не помогает и не просит. Идёт половина соседей (не меньше одного, без командира), ближайшие к просящим: «Идём на помощь!». Идут к центру просящего отряда на навмеше, если туда есть полный путь от ближайшего к центру бойца; нет — к самому этому бойцу (центр может прийтись в ящик, а навмеш на его крыше — островок, куда не дойти). Дошли до **Assist Arrive Radius** (900) — «Мы здесь!». Помогающие делятся с отрядом сведениями о врагах в обе стороны и держатся в **Assist Leash Radius** (2000) от него. Бой у просящих стих на 5 с или прошло **Assist Max Time** (60 с) — «Возвращаемся!». Звать снова — не раньше **Assist Call Cooldown** (30 с).

#### Граната отряда

После **First Squad Grenade Delay** (5 с) от контакта командир назначает бросок, когда враг засел дольше **Grenade Dug In Time** (4 с) и виден последние **Grenade Max Unseen Time** (12 с), или когда врагов кучка (≥ **Grenade Cluster Count**, 2, в **Grenade Cluster Radius**, 400). Бросает не командир, тот, кто на удобной дистанции (лучше около 1200 см), не в пути по приказу и не под подавлением; командир кричит «Гранату туда!». Пауза между гранатами отряда — **Squad Grenade Cooldown** (8–12 с). Своё правило броска у бойца (раздел 10.1) тоже работает.

#### Крики

Крик висит над бойцом в панели 1.8 с (приказ отходить — 2.5 с). Помимо криков выше: «Потеряли бойца!» (ближайший к погибшему), «Минус один!» (убили врага), «Граната!» (бросок).

**Союзники помогают игроку.** Когда враг стреляет по игроку (пуля прошла рядом), или игрок стреляет по врагу, `UNoFearBotSubsystem::RallyFriendsOf` поднимает союзных игроку ботов в радиусе их **Alert Share Radius** от игрока: они получают тревогу с позицией стрелявшего. Это работает и для союзников без отряда.

**Кольца под ногами** рисует `ANoFearHUD` вместе с панелями (раздел 7.2): 24 отрезка радиусом 60 см, внешняя кайма зелёная у союзников и красная у врагов.

| Кто | Кольцо |
|---|---|
| Союзник в отряде | всегда (на экране и не дальше 4000 см) |
| Враг в отряде | при прямой видимости |
| Вожак стаи монстров | двойное красное |
| Напарник, одиночки | нет |

Линии от бойцов к кольцу командира видны 1.5 с: при сборе отряда, когда боец догнал собранный отряд, и при смене командира. Сменилась роль — кольцо 0.3 с вспыхивает белым и перекрашивается. Раненый, который отходит, — кольцо вполовину тусклее. Значок роли стоит в панели рядом с «◆ N».

**Что сейчас делает отряд** (флаг `Show Squad Orders`):
- **слово приказа** в панели рядом со значком роли, цветом роли: «подавляет», «обходит», «перевязка»… (таблица приказов выше; приказ на гранату — «граната»). При новом приказе слово 0.6 с увеличено и светлее;
- **над командиром** — тактика («Фланг», «Отход», «Оборона · рубеж», «Бой · к соседям») и шкала морали от красного к зелёному; ниже 0.25 шкала мигает. Сменилась тактика — надпись вспыхивает;
- **линии приказов на земле**, **Squad Order Line Time** (3 с) после приказа: сплошная со стрелкой цветом роли — куда идти (рубеж, укрытие на фланге, место сбора, свой, к кому послан); красный пунктир — по кому подавлять, оранжевый — куда бросить гранату;
- **кольцо** вспыхивает при новом приказе и пульсирует, пока боец выполняет приказ (всё, кроме «держит»);
- **крики** над бойцами (выше).

Настройки — Class Defaults `NoFearHUD` → **Bots | Squad**: `Show Squad Rings`, `Squad Ring Radius`, `Squad Ring Max Distance`, `Squad Line Time`, `Squad Role Change Time`, цвета ролей и `Squad Ally Border Color`; для приказов — `Show Squad Orders`, `Squad Order Line Time`, `Squad Order Flash Time`, `Squad Fire Line Color`, `Squad Morale Low Color` / `Squad Morale High Color`. Переменная `NoFear.HUD.BotIndicators 0` выключает и кольца.

**Настройки отряда** — Project Settings → Game → **NoFear AI**, разделы **Squad**, **Squad | Morale**, **…| Tactics**, **…| Help**, **…| Assist**, **…| Grenade** (значения по умолчанию — в таблицах выше и в `FNoFearSquadTuning`, `NoFearSquadSubsystem.h`; см. раздел 12). Подсистема копирует их при создании мира. Во время игры — `GetTuning` / `SetTuning` у подсистемы, в Python: `sq = unreal.NoFearSquadSubsystem.get(world); t = sq.get_tuning(); t.fallback_morale = 0.3; sq.set_tuning(t)`. У бойца — `NoFearShooterAIController`, раздел **NoFear | AI | Squad**: `Role Weapons`, `Squad Target Share Penalty`, `Bound Gain`, `Rush Gain`, `Reinforce Search Radius`, `Medic Wait Radius`, `Contact Cover Advance`; в **NoFear | AI | Cover** — `Flank Max Threat Distance`.

Для Blueprint и Python у подсистемы (`UNoFearSquadSubsystem::Get`, в Python — `unreal.NoFearSquadSubsystem.get(world)`):
- состав: `GetSquadRole`, `GetSquadCommander`, `GetSquadMembers`, `GetSquadKnownEnemyCount`, `CountSquadmatesTargeting`, `UpdateSquads`;
- тактика и приказы: `GetSquadTactic`, `GetSquadMorale`, `SetSquadMorale`, `GetSquadOrder`, `GetSquadOrderInfo`, `GetOrderText`, `GetTacticText`, `GetAssistingSquad`, `GetHelperSquad`, `SetExecutingOrder`;
- помощь: `RequestCoveringFire`, `CompleteBandage`, `AbortBandage`, `GetMedicFor`.

У контроллера — `GetSquadRole`, `IsSuppressing`, `GetHealTarget`, `IsAwaitingMedic`; у HUD — `GetSquadRoleColor`, `GetDrawnSquadRingCount`, `GetDrawnSquadLineCount`, `GetDrawnSquadOrderLineCount`, `GetDrawnSquadOrderWordCount`, `GetDrawnSquadTacticCount`.

**Отладка отряда:** `GetSquadDebugText` — тактика с причиной, сколько она идёт, главная угроза (давно ли видели, сколько сидит на месте, дистанция), когда можно фланг, гранату и натиск, ход перекатов и рубеж; у контроллера `GetActiveTaskName` — какая задача дерева сейчас выполняется, `GetFlankSearchStats` — почему не нашлось укрытие на фланге (сколько точек отсеял каждый фильтр `FindCover`, то же — `UNoFearCoverLibrary::GetLastSearchStats`). С `NoFear.AI.Debug 1` подсистема рисует в мире тактику, мораль и причину над командиром, сферу рубежа и линии к точкам приказов (жёлтая — боец в пути, зелёная — дошёл).

## 10. Напарник

- Подойти к зелёному боту и нажать **E** («Завербовать»). Подсказка появляется, когда бот ближе 300 см и примерно перед камерой.
- **E** у своего напарника переключает «Жди здесь» / «За мной». Ждущий напарник остаётся на месте и воюет оттуда, как союзник.
- Напарник идёт за игроком шагом, когда тот рядом и не бежит; отстав дальше 600 см — бежит. В бою не отходит от игрока дальше 900 см, а отстав на 1600 см — бросает цель и догоняет.
- Сколько напарников можно иметь сразу — **Max Companions** у `NoFearPlayerController` (по умолчанию 1). Если лимит занят, самый старый напарник отпускается и остаётся союзником на месте.
- Смерть напарника окончательная: тело остаётся лежать, из списка напарников он пропадает.

### Круг приказов

Держать **Tab** (на геймпаде — крестовина вверх): время замедляется до 0.3, обзор мышью останавливается, в центре экрана круг из 8 секторов. Мышь выбирает сектор, отпускание Tab отдаёт приказ, мышь в центре — круг закрывается без приказа. Точка и враг для приказа — под прицелом в момент открытия круга. Действие ввода создаётся в коде (`IA_NoFearOrderWheel`, свой контекст ввода), ассетов не нужно.

| Сектор | Приказ | Что делает | Ответ |
|---|---|---|---|
| вверх | За мной | Следует за игроком | «Иду за тобой.» |
| вверх-вправо | Атакуй цель | Враг под прицелом. Цель важнее остальных, пока жива | «Атакую!» → «Цель уничтожена.» |
| вправо | Иди туда | Идёт в точку под прицелом и держит её | «Иду туда.» → «На месте.» |
| вниз-вправо | Граната туда | Бросает гранату в точку под прицелом, если игрок не в радиусе взрыва | «Понял, гранату туда.» |
| вниз | Жди здесь | Стоит на месте, воюет оттуда | «Жду здесь.» |
| вниз-влево | Патроны / бинт | Сразу несёт то, что нужнее | «Несу бинт!» / «Тебе пока хватает.» |
| влево | Ко мне | Бросает всё и бежит к игроку | «Иду к тебе.» → «Я рядом.» |
| вверх-влево | Не стрелять / Огонь по готовности | В режиме «не стрелять» не открывает огонь, пока не начнёт игрок или пока напарника не заметят | «Не стреляю.» / «Огонь по готовности.» |

Под названием сектора — подробность: имя врага под прицелом, расстояние до точки, число гранат, запас магазинов и бинтов. Серые сектора недоступны: «Атакуй» без врага под прицелом, «Иди туда» и «Граната» без точки, «Граната» без гранат, «Патроны / бинт» при пустом запасе. Раненый напарник отвечает на любой приказ «Не могу, я ранен!».

После приказа в мире остаётся метка: кольцо «сюда» на точке «Иди туда», пунктирное кольцо радиусом 300 см «граната», красный ромб «ЦЕЛЬ» на цели «Атакуй».

Настройки — `NoFearPlayerController`, **NoFear | Companions | Orders**: `Order Wheel Time Dilation` (0.3), `Order Wheel Dead Zone` (12, сырые единицы мыши), `Order Trace Distance` (8000 см).

### Ранение и подъём

Механика в компоненте здоровья (**Health | Downed**): смертельный удар не убивает, а роняет. Флаг `Can Be Downed` переключается сам:
- у напарника — пока его игрок жив и на ногах (если лежат оба, поднимать некому, и напарник погибает сразу);
- у игрока — пока жив и не ранен напарник. Без напарника, а также когда напарник лежит, игрок умирает как раньше.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Downed Duration | 30 с | Сколько ждёт помощи |
| Downed Time Per Damage | 0.05 с | Каждая единица урона пулей или ударом сокращает таймер |
| Downed Explosion Time Per Damage | 0.15 с | То же для взрывов |
| Revive Health Fraction | 0.3 | С какой долей здоровья встаёт |

Пока лежит: сидит в приседе (анимации лежания у манекена нет), ползёт в 3 раза медленнее (`Downed Move Scale` у тела), не прыгает. Враги и монстры его целью не выбирают и переключаются на других; взрывы и шальные пули по-прежнему ранят и ускоряют таймер.

**Напарник упал** — «Я ранен! Помоги!», потом напоминания. Над ним красный маркер «РАНЕН N с», за краем экрана красная стрелка. Подойти (подсказка «E Поднять (держать E)» — как у вербовки, до 300 см) и держать **E** 3 с (`Revive Hold Time` у контроллера игрока) — круг прогресса. Если игрока ранят, прогресс сбрасывается. Встаёт с 30 % здоровья: «Спасибо, я в строю.»

**Игрок упал** — сидит и отстреливается: разброс вдвое больше плюс 2.5°, перезарядки и гранат нет. Края экрана темнеют, в центре «ВЫ РАНЕНЫ», таймер и «<имя> идёт на помощь — N м» (или «<имя> поднимает вас», «Помощи нет»). Напарник бросает всё («Держись! Иду к тебе!»), бежит под огнём, встаёт сбоку от игрока и поднимает за 3 с («Поднимаю, держись!»); если его ранят, начинает сначала. Настройки — `NoFearCompanionAIController`, **NoFear | AI | Companion | Revive**: `Revive Time` (3 с), `Revive Distance` (150 см).

### Бой рядом с игроком

- Укрытие ищет не дальше 900 см от игрока (`Near Leader Cover Radius`), сбоку или позади него, а не впереди.
- Не стоит на линии огня: оказался ближе 80 см к линии прицела игрока (до 3000 см от камеры) — отходит в сторону со словами «Ухожу с линии огня!».
- Помогает по целям игрока: тот, в кого игрок попал за последние 5 с, важнее на 0.8, тот, кто стреляет в игрока, — на 1, цель приказа «Атакуй» — на 5.

### Припасы

Запас — 3 магазина и 2 бинта, магазин прибавляется раз в 40 с, бинт раз в 60 с. Сам приносит:
- бинт, когда здоровье игрока ниже 40 %;
- магазин, когда у игрока меньше двух магазинов патронов на всё.

Подходит не под огнём и ближе 200 см отдаёт: «Держи бинт!» (+40 здоровья) или «Держи магазин!» (магазин оружия игрока в запас). Между приношениями не меньше 8 с. По приказу несёт сразу то, что нужнее: бинт, если здоровья совсем мало или патронов ещё хватает.

Настройки — **NoFear | AI | Companion | Supply**: `Max Supply Magazines`, `Max Supply Bandages`, `Magazine Refill Time`, `Bandage Refill Time`, `Bandage Heal`, `Supply Health Fraction`, `Supply Cooldown`, `Supply Give Distance`.

### Скрытность, отметки, реплики

- **Скрытность.** Игрок крадётся в приседе вне боя, напарник идёт следом — тоже приседает («Понял, тихо.»), не стреляет первым, реплики в рации шёпотом. Игрок выстрелил или их заметили — бой как обычно.
- **Отметки.** Враг, которого видит напарник, а игрок нет, отмечается оранжевым ромбом на 6 с (`Mark Time`), за краем экрана — стрелкой. Новый контакт напарник называет с направлением от игрока: «Контакт сзади, 15 м!», «Монстры слева, 20 м!».
- **Реплики.** Перезарядка, убийство («Готов!»), «Чисто.», «Тебя зацепило! Укройся!», граната рядом, похвала за попадание. Не чаще одной за 1.5 с (`Bark Gap`), важные — без очереди. Показываются над головой и в рации слева (`Radio Line Time` у контроллера игрока, 6 с).

## 10.1. Гранаты

**Игрок:** держать **G** — прицеливание: оружие убрано, в руке граната (оверлей GASP `Grenade`), на экране дуга полёта и круг поражения в точке падения. Отпустить — бросок (замах процедурный, поза **Throw**). Запас 3 гранаты, счётчик «◆ N» справа внизу над патронами; после возрождения снова 3. Действие `IA_Grenade` в `IMC_Weapon`.

**Граната** `ANoFearGrenade` отскакивает от поверхностей и взрывается через 3 с после броска. Взрыв:
- урон только тем, до кого прямая линия от гранаты (стены и блоки уровня закрывают, персонажи — нет); полный урон до Inner Radius, дальше спадает к Min Damage на краю радиуса;
- толкает тела в регдолле, громкий шум (слышат боты), подавление стрелков рядом;
- эффект `P_Explosion_Big_A` и звук выстрела — временные.

Настройки — ассет `DA_Grenade` (`UNoFearGrenadeData`, поле **Grenade Data** у компонента **NoFear Grenade** на теле):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Fuse Time | 3 с | Запал от броска |
| Radius / Inner Radius | 500 / 150 | Радиус поражения / полного урона |
| Max Damage / Min Damage | 150 / 10 | Урон в центре / на краю |
| Friendly Fire | выкл | Урон своим (бросивший бьёт себя всегда). Выключен — свои от гранаты не убегают, их она не подавляет и мораль отряда не роняет |
| Impulse Strength | 900 | Толчок регдоллов |
| Suppression Radius / Amount | 900 / 0.9 | Подавление стрелков |
| Noise Range | 4000 | Дальность шума |
| Danger Notice Radius / Hear Radius | 900 / 450 | Бот видит упавшую гранату / слышит стук без видимости |
| Evade Margin | 200 | Насколько дальше радиуса убегать |
| HUD Warning Radius | 1000 | Значок «ГРАНАТА N м» у игрока |
| Throw Speed / Throw Pitch Offset | 1500 / 10° | Скорость броска игрока, подъём над прицелом |

Компонент **NoFear Grenade** (`UNoFearGrenadeComponent`): `Max Grenades`, `Starting Grenades` (3), `Aim Overlay State`, `Release Delay`, `Recover Time`; для ботов `Bot Windup Time`, `Bot Arc Param`, `Bot Landing Tolerance`.

**Уход от гранат.** Любой бот (стрелок, монстр, напарник, мирный), увидевший гранату в 900 см или услышавший её в 450 см, бежит из радиуса взрыва + 200 см, затем возвращается к дереву. Мирный вдобавок паникует. Отключается **Evade Grenades** в контроллере. Игроку значок с расстоянием над гранатой (красный — внутри радиуса, мигает чаще к взрыву), за краем экрана — стрелка.

**Бросок ботов** — `NoFearShooterAIController`, раздел **NoFear | AI | Grenade**. Запас — **Bot Grenades** (у стрелков 2).

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Throw Grenades | вкл | Бросать ли вообще |
| Grenade Cooldown | 10–15 с | Пауза между бросками |
| First Grenade Delay | 5–8 с | Не раньше стольких секунд после начала боя |
| Min / Max Grenade Distance | 600 / 2000 | Дальность до цели |
| Hidden Target Time | 4 с | Цель не видна дольше — выкурить |
| Max Unseen Time | 12 с | Дольше — уже не знает, где цель, не бросает |
| Cluster Radius / Count | 400 / 2 | Враги кучкой у цели — повод бросить |
| Friendly Grenade Margin | 150 | Свои ближе Radius + этого к точке падения — не бросать |

## 12. Нагрузка и общие настройки

**Общие настройки ИИ** — Project Settings → Game → **NoFear AI** (`UNoFearAISettings`, хранятся в `Config/DefaultGame.ini`). Подсистемы копируют числа при создании мира, поэтому правка действует со следующего запуска игры. Разделы:

- **Squad…** — числа отрядов (раздел 9.2), **Pack** — числа стай (раздел 8.3). На ходу — `GetTuning` / `SetTuning` у `UNoFearSquadSubsystem` и `UNoFearPackSubsystem`.
- **Fear** — числа страха (раздел 7.5). На ходу — `GetTuning` / `SetTuning` у `UNoFearFearSubsystem`.
- **Lod** — уровни детализации ботов, ниже.
- **Search** — лимиты поиска точек, ниже.
- **HUD** — `Max Bot Panels` (24) и `Max Squad Rings` (12): больше панелей над ботами и колец под ногами не рисуется, ближние вытесняют дальние.

**Уровни детализации** (`UNoFearAILodSubsystem`, раз в `Interval` 0.25 с). Уровень бота — по расстоянию до камеры игрока: ближе `Near Distance` (2500 см) — Near, ближе `Mid Distance` (5000) — Mid, дальше — Far. Вниз уровень меняется, только когда бот ушёл за границу на `Hysteresis` (10 %), чтобы не дёргался. Бот, чья цель — игрок, всегда Near.

| | Near | Mid | Far |
|---|---|---|---|
| Решения контроллера (`UpdateBot`) | `Update Interval` (0.25 с) | ×`Mid Think Scale` (1.6) | ×`Far Think Scale` (3) |
| Линия огня и подавление (`NoFearCombatComponent`) | `Update Interval` (0.1 с) | ×`Mid Combat Scale` (1.5) | ×`Far Combat Scale` (3) |
| Анимация | каждый кадр | URO | URO; за кадром — только монтажи (`Freeze Far Offscreen Pose`) |
| Точки-кандидаты укрытия | все | ×`Mid Sample Scale` (0.75) | ×`Far Sample Scale` (0.5) |

URO (`Anim Update Rate Optimization`) — пропуск кадров анимации по размеру бота на экране, за кадром — раз в 4 кадра. Деревья поведения не трогаются: они и так работают по событиям.

**Лимиты поиска.** За кадр не больше `Cover Searches Per Frame` (2) полных поисков укрытия и `Location Searches Per Frame` (3) поисков точки (бегство, обход, Find Location). Плановые поиски (периодическая проверка укрытия стрелка, отход раненого, перепланирование бегства мирного) при исчерпанном лимите ждут следующего кадра. Первая реакция — паника, уход от гранаты, приказ отряда — лимит не ждёт.

**Нагрузочный тест.** В консоли игры:

- `NoFearStressTest 40 battle` — убрать ботов (кроме напарника) и расставить 40 вокруг игрока на навмеше: союзный отряд, три вражеских отряда на 30–60 м, две стаи монстров на 40–70 м, 10 мирных; больше 40 — дополнительные вражеские отряды. `calm` вместо `battle` — то же в 2.5 раза дальше, бои начинаются не сразу.
- `NoFearPerf 10` — замер на 10 с, в лог строка `NOFEAR_PERF`: FPS, время кадра и игрового потока (среднее / 95 % / максимум), сколько ботов на каждом уровне, сколько поисков отложено, и время по системам за кадр (решения, бой, отряды, стаи, укрытия, поиск точек, HUD, позы, LOD).
- `NoFear.AI.Lod 0` — выключить уровни детализации (для сравнения), `NoFear.AI.LodDebug 1` — подписать над ботами уровень и интервал решений.

Замер в Development, окно 1280×720, 40 ботов, бой:

| | FPS | Кадр, мс | Код ИИ, мс |
|---|---|---|---|
| Без уровней (`NoFear.AI.Lod 0`) | 61–65 | 15.3–16.3 | 1.0–1.2 |
| С уровнями | 73–74 | 13.5–13.7 | 1.0–1.2 |
| С уровнями, `calm` | 93–106 | 9.5–10.8 | ~0.3 |
| С уровнями, 60 ботов | 53–59 | 17.0–18.9 | 1.3–1.7 |

Код ИИ — всё, что считает `NoFearPerf`, из них HUD — 0.2–1 мс. Это малая часть кадра; основное — движение персонажей, анимация и отрисовка, поэтому больше всего даёт URO.

## 13. Чего пока нет

- Эффект и звук взрыва гранаты временные (`P_Explosion_Big_A`, звук выстрела), граната в руке и в полёте — простая сфера движка.
- У монстров нет анимации ударов: работают процедурные позы Swing, Lunge, Spit и Roar, слот `Montage` пустой.
- Прыгун, плевун и танк — манекен с другим цветом и масштабом, своих моделей нет. Звуков плевка, лужи и тарана нет (слоты есть).
- Укрытия ищутся на C++ (раздел 9.1). Классы `EnvQueryContext_NoFearThreat` и `EnvQueryTest_NoFearCover` для EQS остались, но в деревьях не используются.
- Подавление только удлиняет время в укрытии (×1.5); отдельной ветки «залечь» нет.
- Точки открытого боя не проверяются на полный путь: бот на отдельном острове навмеша (например, на ящике) стоит и стреляет с места.
- Отрядами командует только ИИ: игрок приказов не отдаёт, союзный отряд игрока не слушает.
- Санитар перевязывает без анимации: стоит присев 4 с.
- Раненый не лежит, а сидит в приседе (анимации лежания у манекена нет); подъём и передача магазина и бинта — без анимации.
- Круг приказов командует одним напарником — первым живым из списка.
- Порталы без звука и эффектов частиц — из фигур движка. Транс проводника и освобождение героем — процедурная поза, без анимации.
- Герой успокаивает мирного без анимации и реплик. Страх пока не меняет позы мирных (ступор при ужасе — с похищениями, этап 14 в `Game_Roadmap.md`).
