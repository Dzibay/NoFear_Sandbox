# Здоровье, урон и интерфейс

Всё написано на C++ и работает без настройки в редакторе. Нужно только пересобрать редактор (см. `Weapons_Setup.md`, шаг 0) и открыть проект через `C:\NoFear_Sandbox\...\NoFear_Sandbox_UE_Project.uproject`.

| Класс | Что делает |
|---|---|
| `UNoFearHealthComponent` | Здоровье, множители зон тела, огонь по своим, восстановление, смерть. Уже стоит на `ANoFearCharacter`, значит и на `CBP_SandboxCharacter`. |
| `ANoFearCharacter` | Передаёт урон компоненту здоровья, при смерти включает рэгдолл, отключает управление и оружие. |
| `ANoFearPlayerController` | Подтверждение попаданий для маркера, смерть игрока и перезапуск уровня, консольные команды для проверки. |
| `ANoFearHUD` | Весь интерфейс: здоровье, патроны, слоты оружия, маркер попадания, указатели урона, виньетка, экран смерти, перекрестие. |

## Как наносится урон

Выстрел оружия делает `ApplyPointDamage`, а он приходит в `ANoFearCharacter::TakeDamage`. Любой стандартный урон работает так же: `Apply Damage`, `Apply Point Damage`, `Apply Radial Damage` из Blueprint или C++.

Меш персонажа теперь **блокирует канал Visibility** (`HitTraceChannel`), иначе пуля не попадала бы по костям, а летела бы сквозь меш и ловила только капсулу. Побочный эффект: тело закрывает обзор, всё, что проверяется трассой по Visibility (в том числе зрение будущих ботов), теперь упирается в тела.

### Зоны тела

Множитель берётся из кости, в которую попала пуля.

| Зона | Кость | Множитель |
|---|---|---|
| Голова | `head` | ×2.5 (считается хедшотом) |
| Шея | `neck_01` | ×1.5 |
| Плечи и бёдра | `upperarm_l/r`, `thigh_l/r` | ×0.75 |
| Руки ниже плеча и ноги ниже бедра | кисти, предплечья, голени, стопы | ×0.75 (наследуют множитель родительской кости) |
| Всё остальное | туловище, таз | ×1 |

Настройка: компонент здоровья → **Health → Damage**: `Head Bone`, `Head Multiplier`, `Bone Multipliers` (кость → множитель, действует и на кости ниже по иерархии).

Урон без точки попадания (`Apply Damage`, падение, взрыв) идёт с множителем ×1.

### Огонь по своим

По умолчанию **выключен**: урон от пешки своей команды (`ENoFearTeam`) игнорируется, компонент возвращает 0, маркер попадания не показывается. Включается флагом **Allow Friendly Fire** у конкретного персонажа. Урон от самого себя и урон без источника проходят всегда.

Мёртвый персонаж урон не получает.

## Параметры (`UNoFearHealthComponent`)

| Поле | Значение по умолчанию | Что значит |
|---|---|---|
| **Max Health** | 100 | Максимум здоровья |
| **Allow Friendly Fire** | выкл | См. выше |
| **Head Bone / Head Multiplier** | `head` / 2.5 | Зона головы |
| **Bone Multipliers** | шея 1.5; плечи и бёдра 0.75 | Остальные зоны |
| **Regen Rate** | 0 | Скорость восстановления в секунду. Ноль — восстановления нет: героя лечат бинт и аптечка из кейса (`Docs/Inventory_Design.md`) |
| **Regen Delay** | 8 с | Сколько секунд после последнего урона ждать до начала восстановления |
| **Regen Player Only** | вкл | Восстанавливается только игрок; боты и монстры нет |

События для Blueprint: `On Health Changed`, `On Damaged` (в нём структура `FNoFearDamageInfo`: сколько снято, кость, хедшот, фатальный ли, откуда пришёл урон), `On Death`. Функции: `Get Health`, `Get Health Fraction`, `Is Dead`, `Heal`, `Set Health`, `Kill`, `Find Health` (по актору или пешке контроллера), `Is Actor Dead`.

## Смерть

Что происходит с любым `ANoFearCharacter`:

1. Оружие переходит в состояние «убрано» (висит на спине или поясе) и больше не стреляет, перезарядка и доставание обрываются. Отдельным предметом оно не выпадает: остаётся на теле и исчезает вместе с ним.
2. Для бота: останавливаются движение и логика AI, контроллер отсоединяется. Для игрока: пешка отдаёт смерть контроллеру.
3. Капсула без коллизии, движение отключено.
4. **Рэгдолл**: тело падает, толчок направлен по линии выстрела в ту кость, куда попала пуля.
5. Через **Corpse Life Span** секунд тело исчезает.

Настройка на `ANoFearCharacter` (категория NoFear): **Ragdoll On Death** (вкл), **Corpse Life Span** (30 с; 0 — не исчезает), **Ragdoll Impulse** (20000), **Hit Trace Channel** (Visibility).

## После гибели игрока

После смерти камера остаётся на теле, двигаться нельзя. Возрождения нет: HUD пишет «ВЫ ПОГИБЛИ», через **Restart Prompt Delay** (1.5 с) добавляет «[Enter] Начать заново», и Enter (Start на геймпаде) загружает текущий уровень заново. Тело лежит до своего исчезновения.

- На `ANoFearPlayerController`: **Auto Respawn** (выкл), **Respawn Delay** (5), **Restart Level On Death** (вкл), **Restart Prompt Delay** (1.5). Включённый Auto Respawn возвращает прежнее: через Respawn Delay секунд игрок возрождается новой пешкой с полным здоровьем на `PlayerStart` (если его нет, там, где игрок появился в первый раз). `Respawn Player` вызывается из кода и консоли независимо от флага.
- События: `On Player Died`, `On Player Respawned`, `On Hit Confirmed`.

## Интерфейс

Рисует `ANoFearHUD`, он уже выставлен в `ANoFearGameMode`. Размеры заданы для 1080p и масштабируются под разрешение.

| Элемент | Где | Поведение |
|---|---|---|
| Здоровье | слева внизу | Число и полоска. Урон белым «хвостом» догоняет полоску. Ниже 30% становится красной, по краям экрана включается пульсирующая виньетка. |
| Патроны | справа внизу | Название оружия, магазин / запас. «ПЕРЕЗАРЯДКА» во время перезарядки, «ПЕРЕЗАРЯДИТЕ» при пустом магазине, «НЕТ ПАТРОНОВ». |
| Слоты оружия | снизу по центру | По слоту на каждый ствол, с номером и названием, текущий подсвечен. |
| Перекрестие | центр | Как раньше: зазор равен разбросу, краснеет на враге. Мёртвый враг красным не считается. |
| Маркер попадания | вокруг перекрестия | Белый крест при попадании, жёлтый при хедшоте, красный и крупнее при убийстве. |
| Указатели урона | вокруг перекрестия | Клин в сторону стрелявшего, поворачивается вместе с камерой, гаснет за 2 секунды. |
| Вспышка и виньетка | края экрана | Красная вспышка при каждом ударе, постоянная виньетка при низком здоровье. |
| Экран смерти | весь экран | Затемнение, «ВЫ ПОГИБЛИ» и «[Enter] Начать заново» (с Auto Respawn — обратный отсчёт возрождения). |

Подстроить можно в Class Defaults Blueprint-наследника `ANoFearHUD` (поставь его в World Settings → HUD Class) или поменяв значения по умолчанию в `NoFearHUD.h`:

- **NoFear|HUD**: флаги `Show Health / Ammo / Weapon Slots / Hit Marker / Damage Indicators / Vignette / Death Screen`, `Margin`, `Hud Font`.
- **Crosshair**, **Hit Marker**, **Health** (цвета, порог низкого здоровья, время «хвоста», длительность и радиус указателей), **Death** (время затемнения).
- **Text**: все надписи (`Dead Text`, `Respawn In Text` с `{0}` под секунды и т. д.), их можно перевести.

Шрифт по умолчанию — Roboto движка, кириллица в нём есть. Если в своём шрифте не хватает букв, подставь свой в **Hud Font**.

## Проверка в редакторе

Противников с ИИ пока нет, поэтому проверка такая.

1. **Попадания.** Поставь на уровень ещё один `CBP_SandboxCharacter` (по умолчанию он в команде NPC) и постреляй: в корпус, в руку, в голову. Должны появляться маркеры (жёлтый на голове), урон считается по зонам, на смерти враг падает рэгдоллом и пропадает через 30 секунд.
2. **Урон по игроку.** Открой консоль (`~`) и введи `NoFearHurt 30`: упадёт полоска с белым хвостом, красная вспышка. Без числа снимается 25. Здоровье само не вернётся: нужны бинт или аптечка (Regen Rate 0; с ненулевым значением восстановление начнётся через Regen Delay секунд). `NoFearHurt 75` покажет низкое здоровье: красная полоска и виньетка.
3. **Смерть.** Команда `NoFearKill`: тело валится, экран темнеет, «ВЫ ПОГИБЛИ», через 1.5 секунды «[Enter] Начать заново», и Enter начинает уровень заново.
4. **Огонь по своим.** Поставь манекену в **Team** значение Player и стреляй: урона нет, маркера нет. Включи у его компонента здоровья **Allow Friendly Fire**, и урон пойдёт.

## Что проверено автоматически

Сценарий без графики, чтобы не зависеть от экрана: обычный урон; все зоны тела (включая дочерние кости); огонь по своим выключен/включён; настоящие выстрелы с попаданием в `head` с хедшотом и убийством за два выстрела; урон по игроку с указателем, вспышкой и «хвостом»; восстановление игрока без восстановления у NPC; смерть бота (рэгдолл падает, капсула без коллизии, движение выключено, труп урон не получает, оружие убрано); смерть игрока (стрелять нельзя, отсчёт, возрождение новой пешкой с полным здоровьем и тремя стволами, старое тело остаётся); консольные команды. Отдельным запуском с графикой сняты три кадра HUD (обычный, урон, смерть).

Не проверялось руками: ощущение от настроек (громкость маркеров, размеры, скорость восстановления) и поведение с несколькими игроками (сетевой режим). Параметры подбирай по месту.
