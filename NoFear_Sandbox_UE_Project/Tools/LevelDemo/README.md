# L_Demo: генератор уровня и прогоны

Небольшой линейный уровень `/Game/Levels/L_Demo` из серых боксов для показа механик ИИ.
Карту не правят руками: её целиком собирает `build_demo.py` из пустой карты, поэтому менять расстановку нужно в нём и затем пересобирать.

## Маршрут

| Зона | Что показывает |
|---|---|
| Старт | телепорты-срезки к руинам, складу и финалу; в каждой зоне площадка обратно |
| Деревня | спокойные мирные |
| Резерв и блокпост против рейдеров | бой отрядов, блокпост зовёт резерв, отход после гибели командира |
| Сарай у дороги | двое мирных слышат бой, паникуют и прячутся, наружу не выходят |
| Загон | бешеный монстр, который не может выбраться |
| Руины | стая: бродит, окружает, дерётся внутри руин и не выходит за них |
| Двор и дом | напарник Макс; вербовка на E, дальше идёт за игроком |
| Склад | отряд с отходом к задней линии; пленные сбегают при начале боя |
| Арена | бой трёх сторон: отряд, игрок и трое бешеных из камер, которые выходят на стрельбу |

Ограничения: стаю держат в зонах полосы без навмеша, поэтому Макс за них не проходит и телепортами не пользуется, а идёт с игроком только от дома дальше.
Камеры арены соединены с ней односторонними off-mesh связями (тайл навмеша 9,88 м, связь цепляется только в соседний тайл), а навмеш коридора начинается в 16+ м от камеры, чтобы спокойный монстр не выбрёл наружу.

## Запуск

Редактор должен быть закрыт. Скрипты берут проект по ASCII-ссылке `C:\NoFear_Sandbox`, а движок из `/d/Epic Games/UE_5.8`; если пути другие, задайте `NOFEAR_PROJECT` и `UE_ROOT`.

```bash
./rebuild.sh
```

Пересобирает карту и запекает навмеш. Ожидается `problems 0` и `Success - 0 error(s)`.

```bash
./run.sh t1_nav.py
```

Прогоняет сценарий в `-game` без окна и печатает строки `NFT` из лога. Логи пишутся в `Saved/LevelDemo/`.

| Сценарий | Проверка |
|---|---|
| `t1_nav.py` | связность навмеша, полосы без навмеша, 60 с простоя без драк и побегов |
| `t2_outpost.py` | бой блокпоста с рейдерами, помощь резерва, паника в сарае |
| `t3_ruins.py` | бой со стаей в руинах, стая и бешеный из загона остаются на месте |
| `t4_companion.py` | вербовка Макса и путь за игроком от дома до склада |
| `t5_warehouse.py` | бой на складе, отход отряда, реакция пленных |
| `t6_finale.py` | бешеные выходят из камер на арену и дерутся с отрядом |
| `t7_inventory.py` | кейс героя: стартовый минимум, подбор на E, патроны и гранаты из кейса, выброс, расширение. Печатает `PASS`/`FAIL` и `RESULT OK` |
| `t9_case_screen.py` | экран кейса на I: замедление и курсор, перенос щелчком и перетаскиванием, подсветка, поворот, разделение и доливка, колесо (1–8, перетаскивание, очистка), меню ПКМ, выброс, подбор без места. Печатает `PASS`/`FAIL` и `RESULT OK` |

Общая обвязка сценариев лежит в `t_lib.py`. Она выдаёт герою прежний набор `NoFear.Inv.Kit` (три ствола и гранаты), а сценарий, которому нужен стартовый минимум, ставит `KIT = False` до `exec`. Игрок в сценариях бессмертный, поэтому исход боёв зависит только от ботов и от прогона к прогону может отличаться.
